# JSV — Jagdeep Singh Virdi

Personal portfolio for [jagdeepsinghvirdi.com](https://jagdeepsinghvirdi.com).

## Stack
- Semantic HTML, CSS and vanilla JavaScript
- Google Fonts: Sora, DM Sans and DM Mono
- No build step, framework, runtime dependency, analytics or tracking scripts

## Run locally
Open `index.html` directly in a browser, or serve this directory with any static HTTP server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy
This is a static website. Publish the repository root using GitHub Pages, Cloudflare Pages, Netlify or Vercel. No build command is required; the output directory is the repository root.

## Project structure
- `index.html` — complete responsive portfolio
- `favicon.svg` — JSV browser icon
- `robots.txt` — crawler policy
- `sitemap.xml` — canonical homepage sitemap

## Before launch
- Confirm all project destinations and availability labels.
- Confirm career dates, role descriptions, operator references and certificate URLs.
- Replace the Open Graph image URL with a designed `og-image.png` when one is prepared.
- Run Lighthouse and verify the custom domain, TLS and production deployment.

## Accessibility and privacy
Includes skip navigation, semantic landmarks, keyboard focus styles, labelled filters, reduced-motion support and no analytics/tracking by default.
